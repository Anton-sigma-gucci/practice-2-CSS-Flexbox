
# Практична робота №2

**Тема:** Проєктування та адаптивна верстка інтерактивної вебформи з медіаелементами засобами CSS Flexbox.

## Мета роботи

Отримати практичні навички створення інтерактивних вебформ із використанням HTML5, CSS3 та JavaScript, навчитися застосовувати CSS Flexbox для адаптивного розташування елементів, а також забезпечувати доступність і перевірку введених даних.

## Завдання роботи

Розробити адаптивну вебформу для створення публікації з медіаконтентом. Форма повинна містити поля для введення назви й опису, вибір категорії, область завантаження зображення або аудіофайлу та налаштування приватності.

## Хід виконання роботи

1. Розроблено структуру вебсторінки засобами HTML5 із використанням семантичних елементів.
2. Створено поля форми для введення назви й опису публікації та вибору категорії.
3. Реалізовано завантаження медіафайлів із пристрою та попередній перегляд зображень і відтворення аудіофайлів.
4. За допомогою CSS3 оформлено елементи інтерфейсу, використано CSS-змінні та Flexbox для розташування компонентів.
5. Додано адаптивність для коректного відображення форми на різних розмірах екрана.
6. Використано JavaScript для обробки вибору файлів, взаємодії з формою та відображення повідомлень.
7. Реалізовано перевірку обов’язкових полів засобами HTML5 та індикатори клавіатурного фокусу.
8. Проведено перевірку HTML-документа за допомогою Nu HTML Checker.

## Використані технології

- HTML5
- CSS3 (Flexbox, медіазапити, CSS-змінні)
- JavaScript
- Figma для проєктування інтерфейсу користувача

## Результат роботи

У результаті виконання практичної роботи створено адаптивну інтерактивну вебформу для створення публікацій із медіаконтентом. Реалізовано введення даних, вибір категорії, завантаження файлів, попередній перегляд зображень, відтворення аудіо та базову перевірку введених даних.

HTML-документ успішно пройшов перевірку в Nu HTML Checker без помилок і попереджень.

## Висновок

Під час виконання практичної роботи було отримано навички створення інтерактивних вебформ, використання семантичної HTML-розмітки, CSS Flexbox та адаптивної верстки. Також було закріплено навички роботи з JavaScript для обробки медіафайлів і взаємодії користувача з вебсторінкою.
