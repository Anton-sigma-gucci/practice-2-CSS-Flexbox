
# Практична робота №2

**Тема:** Проєктування та адаптивна верстка інтерактивної вебформи з медіаелементами засобами CSS Flexbox.

## Завдання роботи

Розробити адаптивну вебформу для створення публікації з медіаконтентом. Форма повинна містити поля для введення назви й опису, вибір категорії, область завантаження зображення або аудіофайлу та налаштування приватності.

## Використані технології

- HTML5
- CSS3 (Flexbox, медіазапити, CSS-змінні)
- JavaScript
- Figma для проєктування інтерфейсу користувача
